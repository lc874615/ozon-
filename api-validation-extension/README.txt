Ozon API 本地验证 0.1.6

本安装包仅API流程，不包含旧页面采集、复制商品、参数表单操作。与旧扩展独立安装，测试时请暂停/停用旧扩展。

安装：解压到新文件夹；浏览器扩展管理→开发者模式→加载已解压扩展，选择包含manifest.json的文件夹。

测试：同一浏览器正常打开Ozon买家页和已登录卖家页，打开本扩展。先填1个数字SKU，确认价格/日期/最低28天销量，并发选1，点开始API验证。初次保持弹窗打开；结束/暂停后点导出API诊断，上传ozon-api-validation.json。单件稳定后再填最多5个源SKU，并发选2；全部变体分别请求，数量可能多于源SKU。

所有商品包括FBS均要求送达>=7天才通过履约项；明确不合格时后续请求可以停止。API核心数据齐全不等于正式选品通过，本版不执行承运资格/利润审核、不发布。品牌未知不拦截，只有已知排除名单命中才排除。

API来源：买家正常JSON、卖家分析、只读SKU/型号搜索；不是全部官方公开Seller API。需要正常登录授权，403/429/验证码停止，不绕过，不读取或导出Cookie/密钥。不调用创建商品、导入、价格或库存写接口。

候选搜索API自动分页和生产队列尚未在此验证包启用；这是全变体/批量字段覆盖测试，不是正式运营版。无变体组件、分页未取全、身份不匹配等会标为未确认，不能冒充已取全。收到数据可能不含人民币价格或全部参数，诊断会保留真实缺失。
