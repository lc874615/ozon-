# 0.5.0 买卖家只读联动与参考条件更新
原0.4.x自动队列只跑买家端，不能自动取得卖家参数页的包装数据。当前版本新增已打开卖家页面的只读同步，新增两个卖家域名访问权限；更新后需允许并重新启用。

## 使用
同一浏览器正常登录卖家后台，打开正常有权访问的选品分析页，切换到28天窗口，加载想核查的SKU。自动队列每次读取买家商品时，会扫描已打开分析表格（最多10个卖家标签）按精确SKU合并。也可手动点击同步按钮。不会自动搜索、翻页、调用未公开分析接口或提升账号权限。
包装数据需要正常打开对应SKU的复制参数页，输入真实来源SKU后点击“确认当前参数页对应上述来源SKU并同步”。这是人工确认关联，非平台自动身份验证。只读带明确包装与毫米/克单位标签的字段，不用商品尺寸重量替代；表单页或内容变化时停止关联，需重新确认。不会自动创建/删除草稿，无法阻止原页面自动保存。不同SKU逐件全自动复制/清理尚未实现。

## 筛选
按用户新规则，用买家明确最短送达天数>=7作参考，不等同已确认FBS；日期展示可按莫斯科日历计算参考差值，推定年份及地区差异保留证据。多个方式取最短，未知待核验。
取消明确无品牌要求，只排除内置国际品牌名称表中的明确品牌；标题出现品牌而无品牌字段时待核验，兼容型号文字不直接证明商品品牌。内置表不是全球品牌全集，不能承诺全部国际品牌识别。
销量只读明确28天售出件数字段，或页面明确选中28天时的售出件数列，不用订购/评论/7天数据替代；不把monthly字段自动标成28天。正常表格未加载SKU时无法补齐。
上架日期只读取明确上架日期列；nullableCreateDate曾见于旧插件，但含义和正常页面可用性仍未在实际账号核验，不推定创建日期等于上架日期。诊断记录表头用于继续定位。
官方28天口径参考：https://seller.ozon.ru/media/news/populyarnye-tovary-stali-udobnee/

## 当前完成边界
完成只读合并、品牌/时效参考调整及模拟测试，真实用户后台布局和字段覆盖待验证。未完成卖家端逐件全自动查找/复制，也不能保证包装、销量、日期已全部采到。正式结果仍仅输出筛选通过项，完成后不执行后续步骤。旧离线CSV/XLSX评估器仍为历史FBS/无品牌规则，此版本新规则作用于浏览器采集与其导出，不应混用旧评估器结论。

# 0.4.8 页面就绪调度与简版参数诊断
替换每步固定30秒的等待：监听页面完成后约1.5秒尝试读取；准备属性后约2.5秒再读；相邻商品导航至少20秒，始终单标签串行。读取前等待DOM约700毫秒安静期，最多等待3秒。闹钟仍用于service worker被挂起后的备用唤醒，不能保证后台定时精度。
既有验证/访问错误暂停、商品身份核对、最多两次属性准备、缺失待核验和正式只导出通过项规则保留。速度没有真实用户页面实测，不能保证固定倍数或全部字段完整。
简版属性增加明确li/role行的双列读取；只有简版、没有完整属性面板时也尝试展开。不能承诺覆盖未知DOM布局。诊断新增受限的简版参数HTML、价格组件HTML、每件经过时间和展开次数，仅用于进一步识别布局与价格类型，不读取Cookie、账号或整页HTML。
FBS、无品牌、官方28天销量、上架日期、已核对人民币售价并未因为调度优化而获得新的数据来源。商品尺寸/商品重量不等同包装尺寸/毛重。

# 0.4.7 中文实时进度
弹窗顶部进度条显示已处理/本批总数、通过/排除/待核验、当前步骤、队列与历史保存数量。打开弹窗时每秒读本地状态，并监听存储变化；关闭弹窗不影响队列运行。不会为刷新界面额外访问Ozon。
已处理100%不代表筛选通过100%。本批有图片、有价格文本的数量分别统计，未核验价格口径不等于已获得可筛选的人民币成交价。每日上架目标仍只是记录；此版本不执行上架。
诊断新增图片数量、价格展示文本与买家来源链接，以便验证实际采集完整性。历史诊断缺这些字段不能据此推断未采集或采集成功。

# 0.4.6 属性加载修复
读不到属性时，最多两次准备：滚动到参数区域，或点击明确命名的本站参数按钮/同页面参数锚点，之后等下一次定时读取。不点击外部链接或提交表单，不处理验证。
增加嵌套dt/dd与简版特征组件读取。仍无属性时保存partial诊断记录并继续下一件，正式结果不包含partial；手动重新开始时可再次尝试这类记录。验证、身份不一致和访问错误仍暂停。
新增导出采集诊断按钮，供核查页面组件与实际读到的字段，不包含Cookie或后台账号数据。诊断与正式通过商品分开导出。
模拟浏览器和队列测试通过，但尚未在用户360实际页面验证；若仍无法采集，请导出诊断供排查。

# 0.4.5 仅导出筛选通过商品
正式导出 observations 只含 pass；exclude/review 仅记为 audit 简要日志，不作为候选商品。原始历史数据不删除。
新增按钮：读取官方分析页已显示的上架日期。需要先正常打开有权访问的官方选品分析页面；只读当前已加载表格，按明确SKU与上架日期列配对，存储来源页、标签、采集时间。下次评估按SKU合并；冲突日期留待核验。
此功能尚未在用户真实卖家页面验证，不能保证该账号提供日期列，也不会主动调用未公开分析接口。插件静态分析发现 nullableCreateDate 被用于日期展示，但仅凭字段名不能证明等同首次开售日期；当前不会盲目读取该内部字段。商品创建日期、首次评论、首次观测时间不替代上架日期。
若正常官方页面不提供明确日期，日期筛选仍无法完成，该商品不会通过。此限制没有被隐藏或以推测数据绕过。

# 0.4.4 启动前筛选
设置上架日期下限（严格晚于，不含当天）、单件售价人民币区间（含上下限，可留空）、近28天最低销量（含下限，至少6件）。默认金额口径为单件售价；可选择近28天销售额，但不得将售价乘销量当作实测销售额。
保留FBS、明确无品牌的强制规则。保存筛选条件后可再次打开插件复用；点击开始也会保存并固定本批条件，不受运行期间修改设置影响。
每件先读取公开页面，再按有明确标签的证据评估：pass、exclude、review。已排除和待核验记录仍保留在历史导出中以便复核，selection_review 给出逐项证据；导出 summary 给出数量。目标是访问/采集件数，不保证通过件数。
重要限制：买家页没有明确上架日期、近28天销量、履约方式或准确人民币售价时，不会猜测或通过。当前仅识别明确属性标签；原始价格组件文本仍保留，但未确定价格口径、币种、促销条件时不强行取其中数字。没有另行调用分析接口或取得竞品私有销量数据。近似人民币展示价也不会自动当成确切成交价；没有经核实汇率时不做外币筛选。
批量采集只读买家页，不自动操作卖家复制页，所以不能承诺这一步取得竞品包装毛重；缺失参数保留缺失。
原有历史采集没有删除；导出时使用当前保存条件重新评估。完成后停止，不触发后续工作。

# 0.4.3 自动采集（仅买家端）
先将搜索页链接读取到队列，或粘贴链接加入队列；设置本批数量（默认5，上限100），点击开始自动采集。插件使用专用后台标签串行打开页面，每30秒执行一步；浏览器需要保持运行，电脑不能休眠。点击查看目标和进度查看 autoQueue 状态，index 表示本批已采数量；完成后导出全部历史采集。
只采集已加载的公开商品字段。不自动翻搜索页，不调用卖家创建接口、不创建草稿、不匹配1688、不核算利润、不发布。
本批队列完成后停止。验证、登录/访问错误、商品身份不一致、页面没有已加载属性时暂停，无自动重试；手动解决后点击开始，新批跳过已保存SKU。刷新或关闭专用标签可能导致暂停，勿用于其他浏览。
新增权限仅为两个买家域名的网站访问及 alarms 定时调度，不读Cookie；卖家表单仍用主动点击的 activeTab 权限。需要在扩展管理页面同意权限并重新启用。没有聊天远程控制通道。
低频率不能保证平台允许自动访问，遇平台限制应停止，不得绕过。不得把本工具宣称为已获得平台批准。
# 0.4.2 采集与参数工作台
覆盖原扩展目录后重新加载，不要卸载或清除数据。
保留原 snapshots 历史数据，新增队列使用独立存储键。买家采集只读已加载DOM和商品组件，不主动展开、滚动或发送页面请求。
使用：保存今日目标；买家搜索页点击读取链接，或粘贴链接加入队列；点击打开下一件，加载后点击采集当前商品；导出历史采集。卖家参数页使用独立参数导出按钮。
队列去重，按已存SKU跳过。不会自动翻页、后台循环访问、创建草稿、填写、保存或发布。云端聊天尚未连接本机浏览器，聊天中的数量指令不能直接触发此插件。
每日目标不是已发布数，实际发布数需经过平台回执核验；当前没有发布实现。
筛选：官方近28天销量大于5、FBS、明确无品牌；缺证据进入待办。所有金额以人民币核算；不得据此把原始外币标签改成人民币。
未采集到的选填参数留空，必填缺失暂停上架。竞品字段只作为参考，不自动等同1688供货SKU的真实参数。
